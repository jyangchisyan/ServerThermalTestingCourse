# 第四課之三：第一個 1-NN 分類器

## 1-NN 如何預測

`1` 代表只找最近的 1 個訓練樣本：

1. 把最近距離初始化為無限大。
2. 逐一計算測試資料到訓練樣本的距離。
3. 遇到更小距離時，更新最近距離與標籤。
4. 檢查完全部樣本後，回傳最近樣本的標籤。

```python
nearest_distance = float("inf")
nearest_label = None
```

`return` 必須放在迴圈外，否則分類器只會檢查第一個樣本。

## 它算是學習嗎

1-NN 沒有推導固定門檻，而是保存訓練案例，預測時尋找最相似的案例。這是第一個由資料決定答案的分類器，也是從手寫規則走向機器學習的重要一步。

## 訓練資料覆蓋不足

只有一個正常與一個異常範例時，新的正常資料 `(0, 0.0, 100)` 仍可能更靠近異常範例，因而產生 FP 誤報。

這表示模型只能根據看過的資料判斷。加入更多有代表性的正常與異常情境，往往比把演算法寫得更複雜更重要。
