# 第一課之二：四版偵測規則

## 第一版：溫度門檻

只要溫度高於 65°C 就判定異常。規則簡單，但高負載正常伺服器也可能超過 65°C，因此會誤報。

## 第二版：頭尾趨勢

同時要求：

- CPU 變化不超過 5%。
- 溫度上升至少 6°C。
- 風扇增加不超過 200 RPM。

它能排除高負載正常資料，卻會漏掉「風扇有加速但散熱無效」的風道堵塞。

## 第三版：升溫速度

同時要求：

- CPU 大致穩定。
- 每分鐘升溫至少 18°C。

升溫速度公式：

```text
(最後溫度 - 最初溫度) ÷ 經過秒數 × 60
```

它能抓到風道堵塞，但因為仍只比較頭尾，所以會漏掉 `61 → 78 → 61` 這種中途尖峰。

## 第四版：逐段升溫速度

第四版逐一比較每兩筆相鄰資料，而不是只比較整段頭尾。每一小段同時要求：

- CPU 變化不超過 5%。
- 每分鐘升溫至少 20°C。

因此 `61 → 78 → 61` 的第一段會被抓到。函式在任一段發現異常時回傳 `True`；只有所有區間都檢查完且沒有異常，才回傳 `False`。

所有門檻目前都只是教學用數字，不能直接當成真實伺服器的安全標準。
