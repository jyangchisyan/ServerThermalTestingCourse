# 第二課之三：未見資料與泛化

## 為什麼需要新資料

只用參與過規則設計的資料評分，就像先看過考題再考試。真正重要的是偵測器能否處理未見過的情境，這種能力稱為泛化（generalization）。

## 風扇追上的正常情境

新測試資料：

```text
時間      CPU  溫度  風扇
10:04:00   50   60   3000
10:04:10   50   65   4200
10:04:20   50   65   4300
```

第一段溫度快速上升，因此第四版立刻判定異常。但風扇已大幅加速，後一段溫度也成功穩定。若人工標籤是正常，這筆結果就是 FP 誤報。

加入這筆新資料後：

```text
TP = 3
TN = 2
FP = 1
FN = 0

Accuracy  = 83.33%
Precision = 75%
Recall    = 100%
```

## 目前規則缺少什麼

第四版只看每一小段的 CPU 與升溫速度，沒有判斷：

- 風扇是否已快速加速。
- 加速後溫度是否在下一段穩定。
- 短暫升溫是正常過渡，還是持續惡化。

後續課程會把這些觀察轉成特徵，並開始區分訓練資料與測試資料，逐步走向機器學習。
