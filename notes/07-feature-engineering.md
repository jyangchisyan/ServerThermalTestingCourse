# 第三課之一：特徵工程

## 原始資料與特徵

原始感測資料每筆包含：

```text
(時間, CPU 負載, 溫度, 風扇轉速)
```

模型需要看出「兩筆資料之間發生什麼變化」，因此我們從相鄰資料提取：

```text
(CPU 變化, 每分鐘升溫, 風扇變化)
```

這組固定順序的數字叫做特徵向量（feature vector）。

## 風扇追上案例

第一段從：

```text
(50%, 60°C, 3000 RPM)
```

變成：

```text
(50%, 65°C, 4200 RPM)
```

提取後的特徵是：

```python
(0, 30.0, 1200)
```

意思是 CPU 沒變、每分鐘升溫 30°C、風扇增加 1200 RPM。第四版規則只用了前兩項，因此忽略了強烈的風扇反應。

## 從資料點變成樣本

三個資料點只有兩個相鄰區間，所以會形成兩個特徵向量。加上標籤後，每個訓練樣本是：

```text
((CPU 變化, 每分鐘升溫, 風扇變化), 正確標籤)
```

例如：

```python
((0, 30.0, 1200), False)
```

在機器學習中，特徵常寫成 `X`，標籤常寫成 `y`。

對應程式位於 `feature_engineering.py` 的 `extract_features()` 與 `make_samples()`。
